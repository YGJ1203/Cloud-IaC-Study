# Docker 사전 맛보기 🐳

> **목표:** 내일 Docker를 처음 설치하기 전에, "Docker가 대체 뭔지"만
> 아주 가볍게 이해하기

## 1. Docker란?

**Docker**는 애플리케이션과 실행에 필요한 환경을 **컨테이너(Container)**
라는 단위로 묶어서 실행하는 기술이다.

쉽게 말하면:

-   VMware → **컴퓨터(OS) 자체를 가상화**
-   Docker → **애플리케이션 실행 환경을 가볍게 분리**

즉, 프로그램마다 필요한 환경을 따로 만들어 실행할 수 있다.

------------------------------------------------------------------------

## 2. 왜 Docker를 사용할까?

서버마다 환경이 다르면 이런 문제가 생길 수 있다.

> "내 컴퓨터에서는 되는데 서버에서는 왜 안 되지?" 💀

Docker는 애플리케이션과 필요한 환경을 함께 관리하기 때문에 **어디서
실행해도 비슷한 환경을 재현하기 쉽다.**

주요 장점:

-   빠른 실행
-   가벼운 자원 사용
-   환경을 동일하게 구성하기 쉬움
-   배포와 삭제가 편리함
-   여러 서비스를 서로 분리해서 운영 가능

------------------------------------------------------------------------

## 3. VM과 Docker의 가장 큰 차이

### 가상머신(VM)

``` text
Hardware
└─ Host OS
   └─ Hypervisor (VMware)
      ├─ Guest OS
      │  └─ Application
      └─ Guest OS
         └─ Application
```

VM마다 **Guest OS 전체**가 존재한다.

### Docker

``` text
Hardware
└─ Host OS
   └─ Docker Engine
      ├─ Container
      │  └─ Application
      └─ Container
         └─ Application
```

Docker 컨테이너는 Host의 **Linux Kernel을 공유**하기 때문에 VM보다
일반적으로 가볍고 빠르다.

------------------------------------------------------------------------

## 4. 내일 가장 먼저 보게 될 용어 3개

### Image

컨테이너를 만들기 위한 **템플릿/설계도**.

예:

``` text
nginx image
httpd image
mariadb image
```

### Container

Image를 기반으로 실제 실행된 **프로세스 환경**.

``` text
Image → Container 생성 → 실행
```

### Docker Hub

Docker Image를 내려받을 수 있는 대표적인 **이미지 저장소(Registry)**.

------------------------------------------------------------------------

## 5. 흐름 하나만 기억하기

``` text
Docker Image
     ↓
Container 생성
     ↓
Container 실행
     ↓
Application 동작
```

예를 들어 nginx 이미지를 사용한다면:

``` text
nginx Image
    ↓
nginx Container
    ↓
Web Server 실행
```

------------------------------------------------------------------------

## 6. 내일 볼 가능성이 높은 명령어

``` bash
docker --version
```

Docker 버전 확인.

``` bash
docker images
```

보유한 Image 확인.

``` bash
docker ps
```

현재 실행 중인 Container 확인.

``` bash
docker ps -a
```

종료된 것을 포함한 모든 Container 확인.

``` bash
docker pull nginx
```

nginx Image 다운로드.

``` bash
docker run nginx
```

nginx Image를 기반으로 Container 생성 및 실행.

> 지금은 명령어를 외울 필요 없음!\
> **Image → Container → 실행** 흐름만 알고 가면 충분하다. 😏

------------------------------------------------------------------------

## 7. 지금까지 배운 내용과 연결하면?

지금까지는 CentOS 서버에 직접:

``` text
httpd 설치
↓
설정 파일 수정
↓
서비스 실행
```

했다면 Docker에서는 앞으로 다음과 같은 형태를 접하게 된다.

``` text
Web Server Image 준비
↓
Container 생성
↓
Web Server 실행
```

즉, 기존에 배운 Linux 서버 지식이 사라지는 것이 아니라 **그 위에
컨테이너 운영 방식이 하나 더 추가되는 것**이다.

# ⭐ 내일 수업 전 이것만 기억하기

``` text
Docker = Container를 이용해 애플리케이션 실행 환경을 분리하는 기술

Image     = 설계도
Container = Image로 만든 실제 실행 환경
Registry  = Image 저장소

Image → Container → 실행
```

VMware를 이미 다뤄봤다면 처음에는 이렇게 비교하면 이해하기 쉽다.

> **VMware는 OS 단위 가상화, Docker는 애플리케이션 실행 환경을 컨테이너
> 단위로 분리한다.**
