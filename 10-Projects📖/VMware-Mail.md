# Outlook에서 메일 서버 수동 설정이 필요한 이유

## 개요

Windows Server 2003 환경에서 POP3 및 SMTP 메일 서버를 구축한 후,
클라이언트(Windows 7)의 Outlook에서 메일 계정을 등록하여
메일 송·수신 환경을 구성한다.

---

## 왜 '수동으로 서버 설정'을 선택하는가?

실습 환경에서는 메일 서버를 내부망(Local Network)에 직접 구축하였다.

따라서 Outlook이 인터넷을 통해 메일 서버를 자동으로 검색(Auto Discover)할 수 없기 때문에
POP3 및 SMTP 서버 정보를 사용자가 직접 입력해야 한다.

즉,

자동 설정 ❌

↓

수동 설정 ⭕

---

## Outlook 설정 과정

1. Outlook 실행
2. '수동으로 서버 설정 또는 추가 서버 유형 구성' 선택
3. POP3 계정 선택
4. 메일 계정 정보 입력

- 이메일 주소
- POP3 서버
- SMTP 서버
- 사용자 이름
- 비밀번호

---

## 입력 예시

메일 주소

user1@kaist.com

POP3 서버

mail.kaist.com
(또는 10.1.103.200)

SMTP 서버

mail.kaist.com
(또는 10.1.103.200)

사용자 이름

user1

비밀번호

(메일 서버에서 생성한 암호)

---

## 계정 설정 테스트

Outlook은 입력한 정보를 이용하여 다음 항목을 확인한다.

- POP3 서버 연결
- SMTP 서버 연결
- 사용자 인증
- 메일 서버 로그인 가능 여부

모든 테스트가 성공하면 메일 서버와 정상적으로 연동된다.

---

## 결과

Outlook은 생성한 메일 계정(user1@kaist.com)으로
POP3/SMTP 서버에 접속하여 사용자 인증을 수행한다.

인증이 완료되면 메일 서버와 연동되어
메일 송·수신이 가능한 환경이 구성된다.

---

## 핵심 정리

- 내부망 메일 서버는 자동 검색이 불가능하다.
- 따라서 Outlook에서 '수동으로 서버 설정'을 선택한다.
- POP3/SMTP 서버 정보를 직접 입력한다.
- 계정 설정 테스트를 통해 서버 연결 및 인증을 확인한다.
- 테스트가 완료되면 메일 송·수신이 가능하다.
