---

# 프로젝트 개요

이번 프로젝트에서는 **VLAN 생성 및 포트 할당, PortFast 설정** 파트를 담당하였다.

단순히 Cisco 명령어를 입력하는 것에 그치지 않고, 실제 네트워크 환경을 고려하여 VLAN을 설계하고 Access Port를 구성하였으며, PortFast를 적용하고 검증하는 과정까지 직접 수행하였다.

또한 발표 자료(PPT)를 제작하면서 설정 결과뿐만 아니라 **왜 이러한 설정을 사용하는지**, **어떻게 검증하는지**까지 함께 설명할 수 있도록 자료를 구성하였다.

# 담당 업무

- VLAN 설계

- PortFast 적용 여부 검증
- 발표 자료(PPT) 제작

# VLAN 구성

각 Access Switch에 필요한 VLAN을 생성하였다.

```bash
vlan 11
 name VLAN_11

vlan 12
 name VLAN_12

vlan 13
 name VLAN_13
```

생성 후에는 다음 명령어를 이용하여 정상 생성 여부를 확인하였다.

```bash
show vlan brief
```

---

# Access Port 설정

사용자 및 서버가 연결되는 포트를 Access Mode로 변경한 후 VLAN을 할당하였다.

```bash
interface Ethernet0/2
 switchport mode access
 switchport access vlan 11
 spanning-tree portfast
```

이를 통해 해당 포트는 VLAN 11에 소속되고 PortFast가 적용된다.

---

# PortFast 적용

PortFast는 PC, Server와 같은 **End Device**가 연결되는 Access Port에서 사용하는 기능이다.

PortFast를 사용하면 STP의 Listening 및 Learning 단계를 생략하여 포트가 즉시 Forwarding 상태로 전환된다.

이를 통해 PC가 부팅된 직후에도 빠르게 네트워크를 사용할 수 있다.

---

# PortFast 설정 시 출력되는 메시지

PortFast를 설정하면 Cisco에서는 두 가지 안내 메시지를 출력한다.

## Warning 메시지

```text
Warning: portfast should only be enabled on ports connected to a single host.
```

### 의미

- PortFast는 단말기(PC, Server) 포트에서만 사용해야 한다.
- Switch와 Switch를 연결하는 포트에서는 사용하지 않는 것이 권장된다.
- STP Loop 발생 가능성이 있기 때문에 Cisco에서 경고 메시지를 출력한다.

---

## PortFast 안내 메시지

```text
%Portfast has been configured on Ethernet0/2 but will only have effect when the interface is in a non-trunking mode.
```

### 의미

- PortFast 설정은 정상적으로 완료되었다.
- 단, Access Port(Non-Trunk)에서만 실제 기능이 동작한다.
- Trunk Port에서는 PortFast의 효과가 적용되지 않는다.

---

# PortFast 적용 확인

PortFast가 정상적으로 적용되었는지 다음 명령어를 통해 확인하였다.

```bash
show spanning-tree interface e0/2 detail
```

출력 결과

```text
The port is in the portfast edge mode
```

위 출력을 통해 PortFast가 정상적으로 적용되었음을 확인하였다.

# 발표 자료 개선

초기 발표 자료는 설정 명령어 위주로 작성되어 있었다.

```bash
switchport mode access
switchport access vlan 11
spanning-tree portfast
```

하지만 발표 자료의 전달력을 높이기 위해 다음 내용을 추가하였다.

- VLAN 생성 결과
- show vlan brief 결과
- PortFast Warning 메시지
- show spanning-tree 검증 결과
- PortFast 동작 원리

이를 통해 발표 흐름을 다음과 같이 구성하였다.

```
설정
    ↓
검증
    ↓
원리 설명
```

단순히 "어떻게 설정했는가"가 아니라 "왜 사용하는가"까지 설명할 수 있도록 개선하였다.

---

# 이번 프로젝트를 통해 배운 점

이번 프로젝트를 통해 이론으로 학습했던 VLAN과 STP 기술을 실제 네트워크 환경에 적용하며 이해도를 높일 수 있었다.

또한 PortFast를 단순히 설정하는 것에서 끝나는 것이 아니라, Cisco에서 출력하는 Warning 메시지의 의미와 사용 목적을 이해하게 되었으며, `show spanning-tree` 명령을 이용하여 실제 적용 여부를 검증하는 방법도 익힐 수 있었다.

발표 자료를 제작하는 과정에서는 설정 결과를 나열하는 것보다 **설정 → 검증 → 원리**의 흐름으로 구성하는 것이 내용을 더욱 효과적으로 전달할 수 있다는 점을 배울 수 있었다.

---

# 느낀 점

이번 프로젝트를 통해 이론으로 학습했던 네트워크 기술을 직접 설계하고 구축하며 실무적인 흐름을 경험할 수 있었다.

또한 팀원들과 역할을 분담하고 지속적으로 의견을 조율하며 하나의 결과물을 완성하는 과정에서 협업의 중요성을 다시 한번 느낄 수 있었다.

앞으로도 단순히 명령어를 암기하는 것이 아니라, **설정의 목적과 동작 원리, 그리고 검증 과정까지 이해하는 학습 방법**을 지속적으로 이어가고자 한다.

---

# 핵심 정리

- VLAN 생성 및 Access Port 구성
- PortFast는 Access Port에서 사용
- Switch 간 연결에는 PortFast 사용 금지
- `show vlan brief`를 통한 VLAN 검증
- `show spanning-tree interface detail`을 통한 PortFast 검증
- Cisco Warning 메시지의 의미 이해
- 발표 자료는 **설정 → 검증 → 원리** 순으로 구성하면 전달력이 향상된다.
