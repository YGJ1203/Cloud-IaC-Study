# KAIST 프로젝트 일일 정리 — 2026.11.18

## 1. 오늘의 진행 내용

- AWS 보안 진단 프로젝트의 개인 담당 PPT 작업 마무리
- 프로젝트 1(프라이빗 클라우드 보안 진단)으로 복귀
- 네트워크 보안 솔루션 담당 역할 확인
- 과거 KAIST IP 대역 및 보안 실습 환경 정리
- 선배 기수 프로젝트 보고서 및 보안 점검 가이드 확보
- AWS 과금 방지를 위한 Terraform 삭제 계획 검토

## 2. 프로젝트 1 역할 분담

| 구분 | 주요 업무 |
|---|---|
| 네트워크 공격 | TCP SYN/UDP/ICMP Flood, Nmap, Wireshark |
| **네트워크 보안 솔루션(본인)** | **Snort IDS, FortiGate NGFW, 탐지·차단 로그 분석 및 검증** |
| 웹 보안 솔루션 | 웹 인젝션 공격, Snort IDS, FortiGate WAF |
| 취약점 진단 | Nessus 및 Docker 보안 진단 |
| Kubernetes | Kubernetes 보안 진단 |

### 담당 파트 핵심

**Snort IDS**
- 네트워크 트래픽 분석 및 공격 탐지
- 탐지 규칙 설정 및 경고 로그 확인
- IDS 자체는 기본적으로 패킷을 차단하지 않음

**FortiGate NGFW**
- 인터페이스 및 라우팅 구성
- 방화벽 정책과 보안 기능 적용
- 트래픽 허용·차단 로그 분석

**검증**
- 공격 전후 통신 상태 비교
- Snort 탐지 로그와 FortiGate 차단 로그 확인
- 결과보고서용 캡처 확보
