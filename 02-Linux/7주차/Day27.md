# 🐧 Linux `vi` 편집기 & 파일 권한 정리

> Linux에서 파일을 직접 편집하는 `vi`와
> 파일/디렉터리의 접근 권한을 관리하는 방법을 정리한다.

---

# 1. vi 편집기

## 1.1 vi란?

`vi`는 Linux/Unix 환경에서 사용하는 대표적인 **텍스트 편집기**이다.

```bash
vi 파일명
```

예시:

```bash
vi test.txt
```

파일이 존재하면 해당 파일을 열고,
존재하지 않으면 새 파일을 생성하여 편집할 수 있다.

---

## 1.2 vi의 핵심 모드

`vi`는 크게 **명령 모드 / 입력 모드 / 마지막 행 모드**로 구분한다.

```text
┌───────────────┐
│   명령 모드   │
│ Command Mode  │
└───────┬───────┘
        │ i, a, o
        ▼
┌───────────────┐
│   입력 모드   │
│  Insert Mode  │
└───────┬───────┘
        │ ESC
        ▼
┌───────────────┐
│   명령 모드   │
└───────┬───────┘
        │ :
        ▼
┌───────────────┐
│ 마지막 행 모드│
│   :wq, :q!    │
└───────────────┘
```

### ⭐ 가장 중요한 원칙

```text
글 작성 → 입력 모드
명령 실행 → 명령 모드
저장/종료 → 마지막 행 모드
```

헷갈리면 일단 **`Esc`**를 누르면 된다. 💀

---

# 2. 입력 모드 진입

| 명령어 | 기능                |
| --- | ----------------- |
| `i` | 현재 커서 위치에서 입력     |
| `I` | 현재 줄의 맨 앞에서 입력    |
| `a` | 현재 커서 다음 위치에서 입력  |
| `A` | 현재 줄의 맨 끝에서 입력    |
| `o` | 현재 줄 아래에 새로운 줄 생성 |
| `O` | 현재 줄 위에 새로운 줄 생성  |

가장 기본적으로는 다음 정도를 먼저 기억한다.

```text
i → 입력 시작
Esc → 입력 종료
```

---

# 3. 명령 모드 주요 명령어

## 삭제

| 명령어   | 기능            |
| ----- | ------------- |
| `x`   | 현재 문자 삭제      |
| `dd`  | 현재 한 줄 삭제     |
| `3dd` | 현재 위치부터 3줄 삭제 |
| `dw`  | 단어 삭제         |

## 복사 / 붙여넣기

| 명령어   | 기능             |
| ----- | -------------- |
| `yy`  | 현재 한 줄 복사      |
| `3yy` | 3줄 복사          |
| `p`   | 커서 다음 위치에 붙여넣기 |
| `P`   | 커서 이전 위치에 붙여넣기 |

## 실행 취소

```text
u
```

직전 작업을 취소한다.

# 4. 저장 및 종료

명령 모드에서 `:`를 입력하여 마지막 행 모드로 이동한다.

| 명령어    | 기능            |
| ------ | ------------- |
| `:w`   | 저장            |
| `:q`   | 종료            |
| `:wq`  | 저장 후 종료       |
| `:q!`  | 저장하지 않고 강제 종료 |
| `:wq!` | 강제로 저장 후 종료   |

### ⭐ 우선 암기

```bash
:wq
```

→ **저장하고 나가기**

```bash
:q!
```

→ **변경사항 버리고 탈출하기** 💀

# 5. vi 검색

파일 내부에서 특정 문자열을 검색할 수 있다.

```text

```

```text

```

```text

```

# 6. Linux 파일 권한

Linux는 파일과 디렉터리에 대해 사용자별 접근 권한을 설정한다.

대표적인 권한:

```text
r = Read
w = Write
x = Execute
```

| 권한  | 의미    | 숫자 |
| --- | ----- | -: |
| `r` | 읽기    |  4 |
| `w` | 쓰기    |  2 |
| `x` | 실행    |  1 |
| `-` | 권한 없음 |  0 |

### ⭐ 핵심 암기

```text
r = 4
w = 2
x = 1
```

---

# 7. 권한 확인

```bash
ls -l
```

예:

```text
-rwxr-xr-- 1 user1 group1 1024 Aug 13 test.sh
```

권한 부분:

```text
-rwxr-xr--
```

다음과 같이 나눌 수 있다.

```text
- | rwx | r-x | r--
    ↓     ↓     ↓
   User Group Others
```

| 영역      | 의미                |
| ------- | ----------------- |
| 첫 번째 문자 | 파일 종류             |
| `rwx`   | 소유자(User) 권한      |
| `r-x`   | 그룹(Group) 권한      |
| `r--`   | 기타 사용자(Others) 권한 |

---

# 8. 첫 번째 문자 의미

예:

```text
-rw-r--r--
drwxr-xr-x
lrwxrwxrwx
```

| 문자  | 의미     |
| --- | ------ |
| `-` | 일반 파일  |
| `d` | 디렉터리   |
| `l` | 심볼릭 링크 |

따라서:

```text
drwxr-xr-x
```

에서 `d`는 **디렉터리**라는 의미이다.

---

# 9. 숫자로 권한 계산하기

권한 숫자는 `r`, `w`, `x` 값을 더해서 계산한다.

```text
r = 4
w = 2
x = 1
```

따라서:

```text
rwx = 4 + 2 + 1 = 7
rw- = 4 + 2     = 6
r-x = 4     + 1 = 5
r-- = 4         = 4
```

---

# 10. chmod

`chmod`는 파일 또는 디렉터리의 **권한을 변경**하는 명령어이다.

```bash
chmod 권한 파일명
```

예:

```bash
chmod 755 test.sh
```

의미:

```text
7 = rwx
5 = r-x
5 = r-x
```

따라서:

```text
rwxr-xr-x
```

가 된다.

---

# 11. 자주 사용하는 권한

## 755

```bash
chmod 755 test.sh
```

```text
User   = rwx = 7
Group  = r-x = 5
Others = r-x = 5
```

결과:

```text
rwxr-xr-x
```

---

## 644

```bash
chmod 644 test.txt
```

```text
User   = rw- = 6
Group  = r-- = 4
Others = r-- = 4
```

결과:

```text
rw-r--r--
```

일반적인 텍스트 파일에서 자주 볼 수 있다.

---

## 700

```bash
chmod 700 private.sh
```

```text
User   = rwx
Group  = ---
Others = ---
```

소유자만 모든 권한을 가진다.

---

# 12. 문자 방식으로 권한 변경

숫자가 아닌 문자 방식으로도 설정할 수 있다.

| 문자  | 의미     |
| --- | ------ |
| `u` | User   |
| `g` | Group  |
| `o` | Others |
| `a` | All    |
| `+` | 권한 추가  |
| `-` | 권한 제거  |
| `=` | 권한 지정  |

예:

```bash
chmod u+x test.sh
```

→ 소유자에게 실행 권한 추가

```bash
chmod g-w test.txt
```

→ 그룹의 쓰기 권한 제거

```bash
chmod o-r test.txt
```

→ 기타 사용자의 읽기 권한 제거

---

# 13. chown

`chown`은 파일이나 디렉터리의 **소유자(Owner)를 변경**한다.

```bash
chown 사용자 파일명
```

예:

```bash
chown user1 test.txt
```

소유자를 `user1`으로 변경한다.

소유자와 그룹을 동시에 변경할 수도 있다.

```bash
chown user1:group1 test.txt
```

---

# 14. chgrp

`chgrp`는 파일 또는 디렉터리의 **소유 그룹을 변경**한다.

```bash
chgrp 그룹명 파일명
```

예:

```bash
chgrp developers test.txt
```

---

# 15. 디렉터리에서 r/w/x의 의미 ⚠️

파일과 디렉터리는 `r`, `w`, `x`의 의미가 조금 다르다.

| 권한  | 파일    | 디렉터리     |
| --- | ----- | -------- |
| `r` | 내용 읽기 | 내부 목록 확인 |
| `w` | 내용 수정 | 파일 생성/삭제 |
| `x` | 파일 실행 | 디렉터리 접근  |

특히 디렉터리의 `x`는 **디렉터리 내부로 접근할 수 있는 권한**이라는 점을 기억한다.

---

# 16. Permission denied 💀

Linux 실습에서 앞으로 매우 자주 만나게 될 메시지:

```text
Permission denied
```

이 메시지가 나오면 다음을 확인한다.

```bash
ls -l
```

그리고 다음 항목을 확인한다.

```text
1. 파일 소유자는 누구인가?
2. 소유 그룹은 무엇인가?
3. 현재 사용자는 누구인가?
4. r/w/x 권한이 적절한가?
5. 실행 파일이라면 x 권한이 있는가?
```

필요하다면:

```bash
chmod
chown
chgrp
```

등으로 수정한다.

# 17. 실습 예제

스크립트 파일 생성:

```bash
vi hello.sh
```

내용 입력:

```bash
echo "Hello Linux"
```

저장 후 종료:

```text
Esc
:wq
```

권한 확인:

```bash
ls -l hello.sh
```

실행 권한 추가:

```bash
chmod u+x hello.sh
```

다시 확인:

```bash
ls -l hello.sh
```

실행:

```bash
./hello.sh
```

결과:

```text
Hello Linux
```

# 19. 오늘의 핵심 ⭐

```text
vi
 ├─ i       → 입력
 ├─ Esc     → 명령 모드
 ├─ :wq     → 저장 후 종료
 └─ :q!     → 저장하지 않고 종료

Permission
 ├─ r = 4
 ├─ w = 2
 └─ x = 1

권한 대상
 ├─ User
 ├─ Group
 └─ Others

관리 명령어
 ├─ chmod → 권한 변경
 ├─ chown → 소유자 변경
 └─ chgrp → 그룹 변경
```

> 🐧 **Linux 권한의 핵심**
>
> **"누가(User/Group/Others), 무엇을(r/w/x) 할 수 있는가?"**
>
> 이 문장 하나를 기준으로 권한 문자열을 해석하면 된다.
