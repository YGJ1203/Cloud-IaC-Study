# 🐧 Linux 설치 전 사전지식 초간단 정리

## 1. Linux란?

* Windows와 같은 **운영체제(OS)**
* 서버, 클라우드, 네트워크, 보안 분야에서 매우 많이 사용
* AWS 등 클라우드 서버에서도 Linux를 자주 사용
* Windows와 달리 **CLI(명령어)** 사용 비중이 높음

---

## 2. Linux 기본 구조

```text
사용자
  ↓
Shell (명령어 입력)
  ↓
Kernel (운영체제 핵심)
  ↓
CPU / RAM / Disk / Network
```

* **Kernel** : 하드웨어와 시스템 자원을 관리하는 핵심
* **Shell** : 사용자의 명령어를 해석해서 Kernel에 전달
* 대표 Shell : `bash`

---

## 3. Linux에서 꼭 알아둘 디렉터리

```text
/
├── home    일반 사용자 홈 디렉터리
├── root    root 관리자 홈 디렉터리
├── etc     시스템 설정 파일
├── var     로그 등 자주 변경되는 데이터
├── tmp     임시 파일
└── bin     기본 명령어
```

⭐ Windows의 `C:\`와 비슷하게 Linux는 `/`에서 시작한다.

---

## 4. 설치 전에 알아둘 개념

### root

Linux의 **최고 관리자 계정**

```text
Windows Administrator ≒ Linux root
```

시스템 설정 변경, 프로그램 설치 등 강력한 권한을 가짐.

### 일반 사용자

평소 작업할 때 사용하는 계정.

필요한 경우 `sudo`를 이용하여 관리자 권한으로 명령을 실행한다.

```bash
sudo 명령어
```

---

## 5. 최소한 이것만 익혀두기 ⭐

```bash
pwd             # 현재 위치 확인
ls              # 파일/디렉터리 목록 확인
cd              # 디렉터리 이동
mkdir           # 디렉터리 생성
touch           # 빈 파일 생성
cp              # 복사
mv              # 이동 / 이름 변경
rm              # 삭제
cat             # 파일 내용 확인
clear           # 화면 정리
```

예시:

```bash
pwd
ls
cd /etc
ls
cd ~
mkdir test
cd test
touch hello.txt
ls
```

👉 이 정도만 직접 입력해봐도 첫 수업 적응에 꽤 도움이 된다.

---

## 6. Linux 경로 개념 ⭐

### 절대 경로

`/`부터 전체 경로를 작성

```bash
cd /home/user/test
```

### 상대 경로

현재 위치를 기준으로 이동

```bash
cd test
cd ..
```

자주 보는 기호:

```text
/    최상위 디렉터리
~    현재 사용자의 홈
.    현재 디렉터리
..   상위 디렉터리
```

---

## 7. Linux는 대소문자를 구분한다 ⚠️

```text
Test.txt
test.txt
TEST.txt
```

Linux에서는 모두 **서로 다른 파일**로 취급한다.

---

## 8. 네트워크 공부와 연결되는 부분

Linux 서버에서도 결국 다음 정보를 설정하게 된다.

```text
IP Address
Subnet Mask / Prefix
Default Gateway
DNS Server
```

즉 네트워크에서 배운

```text
IP → Subnet → Gateway → DNS
```

개념이 Linux에서도 그대로 이어진다.

# 🎯 설치 전 이것만 기억!

```text
1. Linux는 서버에서 많이 사용하는 운영체제
2. CLI 명령어 사용 비중이 높다.
3. 모든 디렉터리는 / 에서 시작한다.
4. root는 최고 관리자 계정이다.
5. pwd → ls → cd부터 익힌다.
6. 절대경로와 상대경로를 구분한다.
7. Linux는 대소문자를 구분한다.
8. 기존에 배운 IP/Gateway/DNS 지식이 그대로 연결된다.
```

## 🔥 초반 핵심 명령어 암기

```bash
pwd     # 나 어디?
ls      # 여기 뭐 있음?
cd      # 이동
mkdir   # 폴더 생성
touch   # 파일 생성
cat     # 내용 확인
cp      # 복사
mv      # 이동
rm      # 삭제
```

**Linux 첫 단계 핵심**

> `pwd → ls → cd`
> 현재 위치 확인 → 주변 확인 → 이동

이 흐름부터 익숙해지면 된다. 🐧
