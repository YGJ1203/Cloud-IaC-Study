## Part 06. 압축과 아카이브

* `gzip`
* `bzip2`
* `zip`
* `tar`

### 핵심

**tar = 여러 파일을 하나로 묶기**

**gzip / bzip2 = 압축**

따라서 `.tar.gz`는

파일 → TAR 아카이브 → gzip 압축

과정을 의미한다.

## Part 15. 자주 발생하는 실수 💀

* 상대 경로 잘못 입력
* `rm -rf` 대상 잘못 지정
* 실행 권한 누락
* vi에서 빠져나오지 못함
* `>`와 `>>` 혼동
* PID를 잘못 지정하여 `kill`
* 압축과 아카이브 개념 혼동
* root 권한으로 위험한 명령 실행
