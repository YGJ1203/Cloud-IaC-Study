# Linux 명령어 학습 정리

> 오늘 학습한 Linux 명령어, Shell 연산자, 메타문자, 정규표현식, 파이프
> 및 리다이렉션 핵심 정리\
> 핵심 관점: **명령어를 하나씩 외우기보다
> `입력 → 검색 → 가공 → 연결 → 출력` 흐름으로 이해한다.**

------------------------------------------------------------------------

## 1. 파일 내용 확인

### `cat`

파일 전체 내용을 출력한다.

``` bash
cat /etc/passwd
cat test.sh
```

-   `.sh` 파일도 일반 텍스트 기반 Shell Script라면 `cat`으로 내용을
    확인할 수 있다.
-   `cat test.sh`는 **내용 확인**이며 스크립트 실행이 아니다.

### `more`

파일 내용을 화면 단위로 나누어 확인한다.

``` bash
more /etc/services
```

### `head`

파일의 앞부분을 출력한다.

``` bash
head -5 /etc/passwd
```

→ 처음 5줄 출력

### `tail`

파일의 뒷부분을 출력한다.

``` bash
tail -2 /etc/passwd
```

→ 마지막 2줄 출력

### 조합 예제

``` bash
head -1 /etc/passwd ; tail -2 /etc/passwd
```

→ 첫 번째 줄을 출력한 뒤 마지막 두 줄을 출력한다.

## 2. 텍스트 가공: `sed`, `awk`

### `sed`

특정 줄을 선택하거나 텍스트를 편집할 때 사용한다.

``` bash
sed -n -e 1p -e 38p -e 39p /etc/passwd
```

-   `-n` : 기본 출력을 하지 않음
-   `-e 1p` : 1번째 줄 출력
-   `-e 38p` : 38번째 줄 출력
-   `-e 39p` : 39번째 줄 출력
-   `p` : print

### `awk`

텍스트를 필드(열) 또는 조건에 따라 처리할 수 있다.

``` bash
awk 'NR>=5 && NR<=20' /etc/passwd
```

-   `NR` : 현재 레코드 번호. 일반적인 텍스트에서는 줄 번호로 이해 가능
-   `>=5` : 5 이상
-   `<=20` : 20 이하
-   `&&` : AND

→ 5\~20번째 줄 출력

``` bash
awk 'NR==1 || NR==38 || NR==39' /etc/passwd
```

→ 1, 38, 39번째 줄 출력

필드 단위 출력:

``` bash
ps -ef | awk '{print $1}'
ps -ef | awk '{print $8}'
```

-   `$1` : 첫 번째 필드
-   `$8` : 여덟 번째 필드

## 3. 검색: `grep`, `egrep`

### `grep`

특정 문자열 또는 패턴이 포함된 줄을 검색한다.

``` bash
grep root /etc/passwd
```

### `grep -E` / `egrep`

확장 정규표현식(ERE)을 사용한다.

``` bash
grep -E '^telnet|^ssh|^http' /etc/services
```

또는:

``` bash
egrep '^telnet|^ssh|^http' /etc/services
```

`egrep`은 전통적으로 `grep -E`에 해당하며, 현재는 `grep -E` 표기가
권장된다.

### `grep -v`

조건과 일치하는 줄을 **제외**한다.

``` bash
ps -ef | grep atd | grep -v grep
```

→ `atd`가 포함된 프로세스를 찾되 검색 과정의 `grep` 줄은 제외

### 오늘의 핵심 예제

``` bash
ps -ef | egrep "UID|atd|/sbin/gdm" | grep -v grep
```

흐름:

``` text
ps -ef
  ↓
전체 프로세스 출력
  ↓ |
egrep "UID|atd|/sbin/gdm"
  ↓
UID 또는 atd 또는 /sbin/gdm 포함 줄 선택
  ↓ |
grep -v grep
  ↓
grep 자체가 포함된 줄 제외
```

`UID`를 검색 조건에 포함하면 `ps -ef`의 헤더도 함께 출력할 수 있다.

## 4. 명령어 연결 연산자

### `;` 세미콜론

앞 명령의 성공 여부와 관계없이 다음 명령을 실행한다.

``` bash
pwd ; ls
```

### `&&` 더블 앰퍼샌드

앞 명령이 **성공했을 때만** 다음 명령을 실행한다.

``` bash
mkdir test && cd test
```

### `||` 더블 버티컬 바

앞 명령이 **실패했을 때** 다음 명령을 실행한다.

``` bash
cd /notfound || echo "이동 실패"
```

### `|` 파이프

앞 명령의 **표준 출력(stdout)** 을 뒤 명령의 **표준 입력(stdin)** 으로
전달한다.

``` bash
cat /etc/services | grep '^telnet'
```

주의:

``` bash
command1 | command2
```

여기서 `|`는 **Shell 파이프**이다.

반면:

``` bash
grep -E 'ssh|http'
```

정규표현식 내부의 `|`는 **OR**이다.

## 5. 메타문자 / 정규표현식 핵심

  문자    의미                           예제
  ------- ------------------------------ ------------
  `^`     줄의 시작                      `^root`
  `$`     줄의 끝                        `bash$`
  `.`     임의의 문자 1개                `a.b`
  `*`     앞 패턴 0회 이상 반복          `ab*`
  `[]`    범위/문자 중 하나              `[0-9]`
  `[^]`   지정 문자 제외                 `[^0-9]`
  `\`     이스케이프                     `\.`
  `|`     OR (`grep -E`)                 `ssh|http`
  `+`     앞 패턴 1회 이상 (`grep -E`)   `a+`
  `?`     앞 패턴 0\~1회 (`grep -E`)     `colou?r`

### 캐럿 `^`

``` bash
cat /etc/services | grep '^telnet'
```

→ `telnet`으로 **시작하는 줄** 검색

### 달러 `$`

``` bash
grep 'bash$' /etc/passwd
```

→ `bash`로 **끝나는 줄** 검색

### 피리어드 `.`

``` text
a.b
```

→ `a`와 `b` 사이에 임의의 문자 하나

### 애스터리스크 `*`

앞 패턴이 0회 이상 반복됨을 의미한다.

``` text
.*
```

-   `.` : 임의의 문자 하나
-   `*` : 앞 패턴 0회 이상

→ 임의의 문자열을 표현할 때 자주 사용

### 스퀘어 브래킷 `[]`

``` bash
grep '[0-9]' file.txt
```

→ 숫자가 포함된 줄 검색

## 6. 따옴표와 명령 치환

### 작은따옴표 `' '`

문자열을 거의 그대로 취급한다.

``` bash
echo '$PATH'
```

→ `$PATH` 자체를 출력

### 큰따옴표 `" "`

변수 및 명령 치환 등을 허용한다.

``` bash
echo "$PATH"
```

→ PATH 변수의 실제 값 출력

### 역따옴표 `` ` ``

명령어 실행 결과를 다른 명령에서 사용할 수 있다.

``` bash
echo `date`
```

### `$()`

역따옴표보다 읽기 쉬운 현대적인 명령 치환 방식이다.

``` bash
echo $(date)
```

일반적으로 `$()` 사용을 권장한다.

### 역슬래시 `\`

특수 문자의 기능을 제거하거나 문자를 이스케이프할 때 사용한다.

``` bash
echo \$PATH
```

→ `$PATH` 문자열 그대로 출력

## 7. 리다이렉션 (Redirection)

명령어의 입력 또는 출력 방향을 파일 등으로 변경한다.

### `>`

출력 결과로 파일을 새로 작성한다.

``` bash
ls -l > list.txt
```

기존 내용이 있으면 덮어쓴다.

### `>>`

기존 파일 뒤에 결과를 추가한다.

``` bash
date >> log.txt
```

### `<`

파일의 내용을 표준 입력으로 사용한다.

``` bash
command < input.txt
```

### 파이프와 리다이렉션 차이

``` text
명령어 A | 명령어 B
```

→ 명령어 A의 결과를 **다른 명령어**에게 전달

``` text
명령어 > file
```

→ 명령어 결과를 **파일**로 전달

## 8. 파일/명령어 검색 및 환경

### `file`

파일의 종류를 확인한다.

``` bash
file test.sh
```

### `PATH`

Shell이 실행할 명령어를 찾는 디렉터리 목록을 저장하는 환경 변수이다.

``` bash
echo $PATH
```

### `which`

현재 PATH를 기준으로 실행되는 명령어 위치를 확인한다.

``` bash
which ls
```

### `whereis`

명령어의 실행 파일, 매뉴얼 등 관련 위치를 검색한다.

``` bash
whereis ls
```

### `alias`

명령어에 별칭을 지정하거나 확인한다.

``` bash
alias
alias ll='ls -l'
```

### `find`

파일/디렉터리를 조건에 따라 검색한다.

``` bash
find /etc -name "*.conf"
```

## 9. 집계·비교·정렬

### `wc`

줄, 단어, 바이트 등의 개수를 확인한다.

``` bash
wc file.txt
wc -l file.txt
```

### `cmp`

두 파일을 바이트 단위로 비교한다.

``` bash
cmp file1 file2
```

### `diff`

두 파일의 내용 차이를 확인한다.

``` bash
diff file1 file2
```

### `sort`

텍스트를 정렬한다.

``` bash
sort file.txt
```

## 10. 사용자 및 그룹

### `su`

다른 사용자 계정으로 전환한다.

``` bash
su user1
```

### `su -`

대상 사용자의 로그인 환경까지 적용하여 전환한다.

``` bash
su - user1
```

`su`와 `su -`는 환경 적용 범위에 차이가 있다.

### `id`

사용자의 UID, GID 및 그룹 정보를 확인한다.

``` bash
id
id user1
```

### `groups`

사용자가 속한 그룹을 확인한다.

``` bash
groups
groups user1
```

### `whoami`

현재 명령을 실행 중인 사용자 이름을 확인한다.

``` bash
whoami
```

## 12. Shell 핵심 개념

Shell은 사용자가 입력한 명령어를 해석하여 운영체제가 실행하도록 연결하는
**명령어 해석기**이다.

``` text
사용자
  ↓
Shell
  ↓
Linux Kernel
  ↓
Hardware
```

대표적인 Shell에는 `bash`, `sh`, `zsh` 등이 있다.

Shell Script는 여러 명령을 파일에 작성하여 순차적으로 실행할 수 있게
만든 스크립트이다.

``` bash
#!/bin/bash

echo "Hello Linux"
date
pwd
```

내용 확인:

``` bash
cat test.sh
```

Bash로 실행:

``` bash
bash test.sh
```

실행 권한이 있다면 직접 실행:

``` bash
./test.sh
```

## 15. 오늘의 핵심 포인트

``` text
Linux 명령어는 하나씩 암기하는 것이 아니라 조합해서 사용한다.

파일/명령의 출력
      ↓
     Pipe
      ↓
검색 (grep)
      ↓
가공 (sed / awk)
      ↓
정렬·집계 (sort / wc)
      ↓
Redirection
      ↓
파일 저장
```

예:

``` bash
cat file.txt | grep 'error' | sort | wc -l
```

각 명령어가 자신의 역할을 수행하고 결과를 다음 명령어로 넘긴다.

> **명령어 = 무엇을 할 것인가**\
> **옵션 = 어떻게 할 것인가**\
> **대상 = 어디에 할 것인가**\
> **파이프 = 다음 명령어에게 결과 전달**
