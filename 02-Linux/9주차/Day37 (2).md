# 🔄 2026-08-28 Linux 종합 복습 노트

> **구분:** Firewall 신규 진도 종료 후 진행한 기존 Linux 과정 복습  
> **환경:** CentOS Stream 9 / VMware / MobaXterm  
> **핵심:** Storage 머신을 새로 구성하고 Storage/RAID/NFS 및 Server 연동 내용을 다시 실습

---

# 1. 복습 시작점

오늘 Firewall 신규 진도가 끝난 뒤에는 **기존에 배웠던 Linux 내용을 처음부터 다시 복습하는 흐름**으로 전환하였다.

이 과정에서 `Storage` 머신을 새로 사용하여 디스크/파티션/RAID/NFS를 다시 구성하였다.

```text
Firewall 신규 진도 종료
        │
        ▼
기존 Linux 내용 처음부터 복습
        │
        ▼
Storage 머신
        │
        ├─ Disk 확인
        ├─ Partition
        ├─ RAID 10
        ├─ Filesystem
        ├─ Mount / fstab
        └─ NFS
             │
             ├─ Server1
             └─ Server2
```

# 2. Storage 디스크 확인

```bash
ls -l /dev/sd*
```

실습에서 확인한 추가 디스크:

```text
/dev/sdb
/dev/sdc
/dev/sdd
/dev/sde
```

각 디스크는 약 2 GiB 규모로 구성하였다.

---

# 3. fdisk로 파티션 생성

예:

```bash
fdisk /dev/sdb
```

주요 입력:

```text
n
```

새 파티션 생성.

```text
t
```

파티션 타입 변경.

RAID 타입:

```text
fd
```

또는 실습에서 확인한 alias:

```text
raid
```

저장:

```text
w
```

같은 작업을 `/dev/sdb`~`/dev/sde`에 반복하였다.

---

# 4. RAID 파티션 확인

```bash
fdisk -l /dev/sd* | grep raid
```

실습 결과:

```text
/dev/sdb1 ... Linux raid autodetect
/dev/sdc1 ... Linux raid autodetect
/dev/sdd1 ... Linux raid autodetect
/dev/sde1 ... Linux raid autodetect
```

---

# 5. RAID 10 생성

4개의 파티션으로 RAID 10을 구성하였다.

```bash
mdadm --create /dev/md10 \
  --level=10 \
  --raid-devices=4 \
  /dev/sdb1 /dev/sdc1 /dev/sdd1 /dev/sde1
```

확인:

```bash
ls -l /dev/md10
```

```bash
fdisk -l /dev/md10
```

실습에서는 `/dev/md10`이 약 3.99 GiB로 확인되었다.

```text
4 × 2 GiB Disk
       │
       ▼
    RAID 10
       │
       ▼
 /dev/md10 ≈ 4 GiB
```

# 6. 파일시스템 생성

```bash
mkfs -t ext4 /dev/md10
```

실습 중:

```bash
mkfs -t ext4 /dev/,d10
```

처럼 장치명을 잘못 입력하여 실패한 뒤 `/dev/md10`으로 다시 실행하였다.

### 복습 포인트

디스크 관련 명령은 오타가 특히 위험하므로 실행 전에 장치명을 반드시 확인한다.

```bash
lsblk
```

```bash
ls -l /dev/md*
```

# 7. `/nfs` 마운트

NFS용 디렉터리:

```bash
mkdir /nfs
```

`/etc/fstab`을 수정하고:

```bash
mount -a
```

실습 결과:

```text
/dev/md10 → /nfs
```

확인:

```bash
df -h
```

결과에서 `/dev/md10`이 `/nfs`에 마운트된 것을 확인하였다.

---

# 8. `/etc/fstab` 복습

`/etc/fstab`은 부팅 시 자동으로 마운트할 파일시스템 정보를 설정하는 파일이다.

수정:

```bash
vi /etc/fstab
```

적용 테스트:

```bash
mount -a
```

실습에서는 수정 후 다음 취지의 메시지가 나타났다.

```text
fstab has been modified,
but systemd still uses the old version
```

따라서:

```bash
systemctl daemon-reload
```

도 실행하였다.

---

# 9. NFS 디렉터리 구조

Storage:

```text
/nfs
 ├─ server1
 └─ server2
```

이를 Server1/Server2에서 각각 사용하도록 구성하였다.

전체 구조:

```text
Storage (192.168.2.205)
        │
        ├─ /nfs/server1
        │        │
        │       NFS
        │        ▼
        │   Server1:/www
        │
        └─ /nfs/server2
                 │
                NFS
                 ▼
            Server2:/www
```

---

# 10. Server1 NFS 마운트 복습

마운트 포인트:

```bash
mkdir /www
```

Storage 연결:

```bash
mount -t nfs 192.168.2.205:/nfs/server1 /www
```

확인:

```bash
df -h
```

실습에서는:

```text
192.168.2.205:/nfs/server1 → /www
```

가 확인되었다.

파일 확인:

```bash
ls /www
```

```text
test1.txt
```

---

# 11. Server2 NFS 마운트 복습

Server2도 `/www`를 생성하고 `/etc/fstab`을 이용해 Storage의 NFS 공유를 마운트하였다.

결과:

```text
192.168.2.205:/nfs/server2 → /www
```

확인:

```bash
df -h
```

```bash
ls /www
```

결과:

```text
test2.txt
```

---

# 12. `mount -a` 복습

```bash
mount -a
```

는 `/etc/fstab`에 정의된 파일시스템을 기준으로 마운트를 수행할 때 사용한다.

따라서 fstab 작성 후 검증에 매우 중요하다.

```text
/etc/fstab 수정
      │
      ▼
   mount -a
      │
      ├─ 성공 → df -h 확인
      │
      └─ 실패 → fstab 내용 점검
```

# 14. 복습용 점검 루틴

Storage/RAID/NFS 문제 발생 시:

```text
① Disk가 존재하는가?
        ↓
② Partition이 존재하는가?
        ↓
③ RAID가 정상인가?
        ↓
④ Filesystem이 존재하는가?
        ↓
⑤ Mount가 정상인가?
        ↓
⑥ NFS Export가 정상인가?
        ↓
⑦ Client/Server에서 NFS Mount 가능한가?
```

주요 명령:

```bash
lsblk

fdisk -l

cat /proc/mdstat

mdadm --detail /dev/md10

df -h

cat /etc/fstab

mount -a
```

# 15. RAID 10 초압축 복습

```text
Disk
 │
 ├─ /dev/sdb1
 ├─ /dev/sdc1
 ├─ /dev/sdd1
 └─ /dev/sde1
       │
       ▼
    mdadm
       │
       ▼
   /dev/md10
       │
      ext4
       │
       ▼
     /nfs
```

생성 명령:

```bash
mdadm --create /dev/md10 \
  --level=10 \
  --raid-devices=4 \
  /dev/sdb1 /dev/sdc1 /dev/sdd1 /dev/sde1
```

# 16. 이번 복습의 핵심

이번 Storage 세션은 **Firewall 신규 진도의 연장선이 아니다.**

Firewall 학습을 마친 후 기존 Linux 내용을 처음부터 다시 복습하면서 새 Storage 환경을 구성한 것이다.

따라서 학습 노트에서도:

```text
[신규]
Firewall / firewalld / Rich Rule

        ≠

[복습]
Storage / Partition / RAID 10
Filesystem / fstab / NFS / Mount
```

처럼 분리해서 관리한다.
