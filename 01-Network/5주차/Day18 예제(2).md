@ 학원 VLAN 구성

강의장 5개 : 1강의장 ~ 5강의장
사무실 2개 : 관리부, 영업부

 - 관리부와 영업부는 브로드케스트 도메인이 동일해야 하며, IP Phone을 사용할 예정이다.
 - 인터넷은 ISP 업체로부터 서비스를 받으며, 게이트웨이를 수행하는 라우터는 1개가 설치될 예정이다.
 - 각각의 강의장과 관리부 사무실, 영업부 사무실에 엑세스 스위치들이 1개씩 설치될 예정이다.
 - 각각의 엑세스 스위치에는 PC들이 연결될 예정이다. 실습이므로 PC 2대만 연결하도록 한다.
 - 단, 관리부 스위치와 영업부 스위치에는 IP Phone이 연결해야 한다. PC/IP Phone 2대만 연결하도록 한다.
   그리고 관리부와 영업부에서 사용하는 PC와 IP Phone은 브로드케스트를 공유해서는 안된다.
 - 각각의 엑세스 스위치 7대는 메인 스위치에 연결해야 한다. 그리고 메인 스위치는 라우터와 연결해야 한다.
 - 이때, 사용하는 스위치들은 3560 스위치를 사용하여라. 라우터는 2811를 사용하여라.

스위치-스위치 연결 : 크로스 오버
스위치-PC : 스트레이트
스위치-Router : 스트레이트
스위치-IP Phone : 스트레이트
IP Phone-PC : 스트레이트

1. SW1~SW8에서 트렁크를 구성하여라.
2. VTP를 이용한 VLAN 정보를 공유하여라.
3. SW1~SW5에서 해당 스위치 포트를 VLAN 도메인으로 Access 하여라
4. SW6~SW7에서 PC를 위한 VLAN 510과 IP Phone을 위한 VLAN 511를 구성하여라. 이때, PC는 Native VLAN을 사용하고, IP Phone은 Voice VLAN을 사용하여라.
5. SW8과 학원 라우터 구간에 Inter-VLAN을 구성하여라. 단, SW8 F0/24 트렁크 포트는 VLAN 501~505, 510~511만 트렁크 사용이 가능하도록 하여라.
6. 학원 라우터에서 DHCP 서버를 구성하여, 각 VLAN 도메인에 포함된 PC/IP Phone에게 IP 주소 정보를 할당하여라. (IP Phone에게는 ‘option 150 ip 172.16.11.254’ 명령어를 이용하여 TFTP 서버 IP 주소 정보도 할당해야 한다. TFTP 서버가 없다면, IP Phone VLAN 511에 대한 게이트웨이 IP 주소로 설정해주면 된다.)
7. PC ‘IP Configuration’에 가서 DHCP를 클릭하여, IP 주소 정보가 할당되는지 확인하여라. 확인이 완료되었다면, 학원 라우터에서 다음과 같은 정보 확인을 실시하여, IP 주소 할당 내용을 확인하여라.
8. PC1에서 PC3(VLAN 502), PC5(VLAN 503), PC7(VLAN 504), PC9(VLAN 505), PC11(VLAN 510), PC13(VLAN 510)으로 Ping 테스트를 실시하여, Inter-VLAN 구성 완료 상태를 확인하여라.
